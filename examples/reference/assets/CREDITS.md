# Reference artwork

city.webp, collaboration.webp, workshop.webp, and digital.webp were generated
for Kujo Presentations with OpenAI Create Image on 2026-10-01, without input
photographs. All scenes and people are illustrative. These are AI-generated
images, not documentary photographs or endorsements.

The artwork is supplied under the project MIT license to the extent applicable;
no exclusive rights to AI-generated images are claimed. See media-sources.json
for per-file hashes, dimensions, encoding, and provenance. The source repository
includes IMAGE_PROMPTS.md with the generation prompts.

Slide headings use Oswald, distributed under the SIL Open Font License in
fonts/Oswald-OFL.txt. Body text uses the existing locally hosted Inter fonts.
Decorative symbols use MIT-licensed Tabler Icons v3.46.0 from SiteKit and the
presentation icon supplement. Their licenses ship beside the icon sprites.
