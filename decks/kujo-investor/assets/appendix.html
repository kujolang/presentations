Language, execution, evidence and assurance

Kujo compiles and executes programs. Spec describes task contracts. PackWrite compiles execution packs. Dispatch orchestrates workflow state. Workcell documents bounded execution. CaseFile captures command output; RunLedger stores supplied run receipts and Git facts. Eval evaluates configured checks; ShipCheck reports release-readiness signals. These components have distinct contracts; no universal enforcement is implied.

The proposed paid service adds shared evidence intake, retention, access control, review and export. Hosted custody, tenant isolation, support and customer validation remain planned work.

Available tooling and scope

  • kujo: VM-first bytecode runtime, compiler and CLI. 1.9.0 release documented. No complete language safety or live-provider certification claim.
  • dispatch: Persisted workflow state, approval gates, retries and recovery. 1.4.1 release documented. Trusted local host; effect assurance beta and participant interoperability alpha are experimental.
  • workcell: Disposable Git workspace, Docker/Podman resource bounds, declared exports, receipt verification. 1.3.0 stable local contract documented. Requires pinned runtime and supported host; no compromised-host protection. Remote adapters alpha, not certified here.
  • eval: Deterministic checks and machine-readable evaluation results. source inspected; local demo separately verified. Only configured checks; no proof of semantic correctness or independent attestation.
  • spec: Task contracts and acceptance criteria. 1.0.2 release documented. A contract does not enforce all runtime boundaries.
  • runledger: Local JSON run receipts, supplied commands/results and Git facts. 1.2.1 release documented. Does not execute or independently prove recorded tests.
  • shipcheck: Explicit release-readiness scans and CI gates. 1.0.2 production-forward alpha. Not release certification; a human decides to ship.
  • casefile: Capture executed command output and exit code into debugging bundles. 1.0.2 documented; demo locally verified. Trusted local host, bounded/redacted logs; successful capture can contain failed command.
  • watchdog: OpenAI-compatible proxy and local telemetry database/dashboard. 1.2.2 release documented. Estimated costs are not invoices. Authentication/TLS/retention are deployment responsibilities.
  • kennel: Kujo package manifests, resolution and installation. source inspected. Package distribution is not adoption evidence.
  • mcp: Kujo MCP server framework and guarded repo scaffolding. 1.3.3 release documented. Remote deployments need ingress/auth/capacity review; not blanket agent integration.
  • packwrite: Compiles prompt/context into validated agent execution packs. 1.1.1 installed. Does not implement the project. Provider availability depends on credentials/model.
  • kujo-workflows: Portable bounded execution/evaluation workflow harness. source inspected; task gates run locally. Bash harness records/gates actions; editorial judgment is performed by this assistant, not a built-in investor judge.
  • presentations: Kujo SSG/SiteKit static deck rendering, notes console, print/read editions. 0.3.1 preview; built locally. Preview APIs may change; fixed 16:9 canvas needs reading edition on small screens.

Command Code, Hermes, OpenCode and Pi adapters are documented in pinned public repositories. Their version-specific tests are not a blanket certification. No hosted paid SKU or active pilot was verified.

A coupon must preserve free shipping

Controlled local checkout fixture, rerun for this briefing. A $50 cart with a 10% coupon incorrectly totals $50.99. One of three Python tests fails. The driver changes shipping eligibility to use the original subtotal; all three unchanged tests then pass. This is a deterministic correction, not an autonomous model repair or customer incident.

What this demonstration establishes

The retained command log also contains the same failing test run without CaseFile. Both paths can preserve output and status; CaseFile supplies a structured bundle and context. No reviewer-time improvement was measured. A future comparison must give reviewers equivalent artifacts and randomize order.

Source’s separate 100-contributor benchmark used scripted Node processes making distinct-section edits, not 100 autonomous LLM engineers. It retained a failed attempt and used explicit private-load limits. See the pinned source record for methodology. This is concurrency and history-retention evidence, not general coding productivity.

Existing alternatives and Kujo’s proposed fit

GitHub Copilot integrates repository tasks and review. LangGraph checkpoints state for recovery and human intervention. CI can execute checks, and observability tooling captures telemetry. Kujo demonstrates local command bundles, explicit evaluation and reviewable exports; a shared service and lower operating effort remain hypotheses. This is a documentation comparison, not hands-on competitive parity testing.

Team subscription scenarios

Proposed $500/team/month ($6,000 annualized). ARR = active paying teams × annual contract. Counts and conversion are unvalidated. The scale ceiling below is a scenario, not a measured addressable market.

17 teams = $102K ARR; 167 = $1.002M; 1,000 = $6M. Base month-24 case: 60 teams = $360K. Conservative: 25 × $300/month = $90K ARR. Upside: 200 × $500/month = $1.2M ARR. Enterprise 100 × $24K = $2.4M is a separate sensitivity excluded from these cases.

What we know and what we are testing

Available now: open local tools, public source and documented host adapters. Planned: a team evidence service at a proposed $500/month; enterprise deployment/support at a separate proposed $24K/year. No paid service, customer revenue or active pilot was verified.

Initial buyer hypothesis: a platform engineering lead reconstructing agent regressions across repositories. Minimum paid scope: intake tied to revisions, retention, search, access controls, review decisions and export/delete. Keep application languages unchanged.

Validation plan: 12 interviews, then 3 qualified design partners and 2 paid pilot conversions over a proposed 90-day program. Ask about actual incidents, reconstruction time, alternatives, budget and purchase process. No interviews or outreach were conducted in this session.

Base assumptions: 1.5% monthly logo churn, 75% gross margin, 1–3 month sales cycle, first revenue around month 6. At $500/month, assumed COGS $125 and gross profit $375; assumed $3,000 CAC implies 8-month payback. Validate with observed cohorts and invoices.

Financing discussion inputs

Proposed $6M raise and $30M post-money SAFE cap require founder confirmation. A cap is not a priced valuation. For a priced round, $6M / $30M = 20% simplified ownership before other dilution; SAFE conversion depends on definitive terms.

This proportional sensitivity does not replace the quarterly hiring schedule. Smaller raises require narrower scope. At $6M, simple ownership at $20M/$30M/$40M post-money is 30%/20%/15%. No agreed terms or close date.

Release spending against evidence

Months 0–6: founder-led discovery, execution reliability and fractional product/DX. Interview 12 buyers and recruit qualified partners. Months 6–12: expand integration and customer engineering only after repeated activation, 3 partners and 2 paid pilots. Months 12–24: expand commercial capacity only after measured retention and support costs.

A $2M–$3M milestone round supports a smaller team and one flagship workflow. $6M supports parallel product, distribution, security and integration work. If buyers cannot identify consequential reconstruction problems or will not pay after evaluation, narrow the product and stop expansion.

Risks and open decisions

Demand and pricing are unvalidated. Local evidence is editable; hosted custody and isolation need security work. Incumbents can bundle similar capabilities. Integration contracts vary and language adoption can be slow. Founder concentration, unknown acquisition costs and future financing are material risks.

Founder decisions remain: wedge and package, pricing, instrument and cap, compensation, hiring gates, approved traction and fundraising contact/timing. The existing public contact link is retained for a diligence conversation. This review draft does not represent agreed financing or authorization to deploy.
