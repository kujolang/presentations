# Phase 06: Navigation, Layouts & Brand Polish

## Goal
Refine the visual and interactive experience to match a "sophisticated venture investor" standard.

## Read before starting
Review the "Design and behavior" section of the MEGA PROMPT.

## Scope
- Native keyboard/pointer navigation tuning.
- Custom layout extensions (only where necessary).
- Typography and spacing refinement.
- Reduced motion and small screen optimization.

## Out of scope
- Changing the core monochrome brand direction.

## Implementation notes
Avoid any gradients or neon. Focus on high-contrast, editorial clarity.

## Acceptance criteria
- [ ] Fullscreen and presenter mode work seamlessly.
- [ ] Reading/Print routes are formatted for professional output.
- [ ] Consistent alignment and density across all slides.
- [ ] Navigation is intuitive and responsive.

## Suggested checks
- Test navigation with both arrow keys and mouse pointer.

## Handoff requirements
- Polished, high-fidelity build.
