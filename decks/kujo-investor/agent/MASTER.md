# Project Master: KUJO Investor Presentation

## Project Goal
Build a high-fidelity investor presentation using the native Kujo Presentations static builder. The presentation must position KUJO as the "programming language and accountability infrastructure for agent-driven development," targeting sophisticated venture investors with a focus on technical evidence, realistic financial modeling, and authentic brand alignment.

## Source of Truth
- **Positioning:** "Trust at the speed of AI."

- **Key Deliverable:** 18 primary slides + comprehensive Appendix + `research/CLAIMS.md`.
- **Brand Identity:** Monochrome, official mark, editorial typography, generous white space, technical diagrams. No stock art or gradients.

## Technical Assumptions

- Native components for navigation, presenter notes, and print routes are available.
- The project will follow the loop-engineering script sequence (A-G).
