# Presentation icons

The arrow-up-right symbol uses SiteKit's existing Tabler sprite. This small
supplement adds `plus` from the same Tabler Icons v3.46.0 outline release:
https://github.com/tabler/tabler-icons/blob/v3.46.0/icons/outline/plus.svg

The SVG paths are unchanged; the standalone icon is wrapped as a sprite symbol.
Tabler is MIT licensed; keep LICENSE.txt with the sprite. Both sprites ship
locally. The decorative slide icons are hidden from assistive technology and
inherit the theme's accent foreground color.
