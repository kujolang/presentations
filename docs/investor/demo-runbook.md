# Reproducible checkout review
Controlled local integration demo derived from kujolang/kujo-hermes at bfa94add10a73d5bda6455dda54c36cb56d8f14c. It is not a production incident or autonomous model repair. A deterministic driver applies the disclosed one-line correction.

From the Presentations repository with Kujo, Python 3, Git and sibling casefile/eval checkouts:

```sh
export KUJO_ECOSYSTEM=/absolute/path/to/kujo-repos
python3 docs/investor/demo/record.py /tmp/new-checkout-evidence
```

Output must not exist. It includes initial Git revision, platform/runtime, commands, before source, unchanged tests, patch, CaseFile bundles, Eval results and SHA-256 manifest. Inspect command records and the child command exit in case.json: CaseFile capture itself can succeed while its child fails.

Task: a $50 original subtotal qualifies for free shipping; a 10% coupon should yield $45. Before: 2 passing tests, 1 failing assertion (5099 vs 4500 cents). Change shipping eligibility from discounted to original subtotal. After: same 3 tests pass. Eval reruns the unchanged test command. RunLedger records this session and is not proof that commands executed.

Controlled comparison: the driver first executes the same failing unittest command without CaseFile, retaining stdout/stderr/exit through Python. CaseFile adds its structured bundle and Git/environment context. Both can preserve evidence; a custom wrapper can do the same. No time-saving percentage or superiority is inferred. Measure reviewer reconstruction time with randomized reviewer order and equivalent artifact access only in a future study.

Capture plan: show task and pinned revision, terminal failure, one-line diff, unchanged tests passing, then before/after case.json and Eval report. Keep the controlled-demo label visible. Capture desktop at 1920×1080 and phone reading view; avoid terminal home paths if making a public video. Narration: “The coupon changed shipping eligibility. Here is the failed assertion, the exact correction, and the same tests passing. The reviewer can inspect both runs without relying on the agent’s summary.” The deck carries all necessary proof without video.
